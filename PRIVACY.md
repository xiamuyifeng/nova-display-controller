# Privacy Policy

## English

Nova Display Controller does not include telemetry, analytics, crash reporting, advertising, account login, or automatic update checks. The application does not transfer information to other networked systems unless specifically requested by the user or the person installing or operating it.

The application processes the following information locally:

- USB HID device identifiers, headset connection state, battery state, volume, and Game/Chat balance;
- CPU and memory usage reported by the operating system;
- media titles, artists, playback state, and progress reported by Windows media sessions;
- images, animations, videos, scenes, settings, and extension packages selected by the user;
- optional diagnostic logs stored in the user-selected local directory.

The experimental GameSense integration communicates only with the SteelSeries GG service on the local computer. Bundled audio and network Providers read local operating-system statistics and do not transmit them externally.

Third-party `.nova-extension` Providers run as separate processes after explicit installation and enablement. They may implement their own network or data behavior and are not covered by the bundled Provider statement above. Review their source and privacy terms before installation.

Diagnostic logs remain local unless the user chooses to share them. Users should remove usernames, paths, media titles, and other personal data before attaching logs to a public issue.

## 简体中文

Nova Display Controller 不包含遥测、数据分析、崩溃上报、广告、账号登录或自动更新检查。除非用户或软件安装/操作人员明确发起操作，本软件不会向其他联网系统传输信息。

软件会在本机处理 USB HID 设备标识、耳机状态、电池和音量信息、CPU/内存使用率、Windows 媒体信息，以及用户导入的素材、场景、设置和扩展包。可选诊断日志仅保存在用户选择的本地目录。

实验性 GameSense 功能只与本机 SteelSeries GG 服务通信。内置音频与网络 Provider 只读取本机操作系统数据，不向外部传输。第三方 `.nova-extension` Provider 在用户明确安装并启用后以独立进程运行，可能具有自己的联网或数据处理行为，安装前应检查其源码与隐私条款。

诊断日志不会自动上传。公开分享日志前，请移除用户名、文件路径、媒体标题和其他个人信息。
